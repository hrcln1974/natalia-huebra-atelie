# Ateliê Natália Huebra — V4.2.0

**Data de validação/release:** 23/09/2026
**Deploy:** pronto para Hostinger; a data efetiva do deploy deve ser preenchida após a publicação no servidor.

## Alterações
- Paleta clareada para champagne, areia, marrom claro e dourado; preto deixou de ser cor dominante.
- Hero preservado, com overlay mais claro e texto legível.
- Destaques ampliados para 8 fotos, com ampliação/lightbox e navegação anterior/próxima.
- Vídeos locais limitados a 3; abaixo deles permanece somente o vídeo do YouTube.
- API pública continua alimentando catálogo, galeria e dados de contato.
- Formulário de agendamento continua registrando lead no CRM e abrindo o WhatsApp.
- Sitemap XML gerado dinamicamente pelo servidor com URLs absolutas; robots aponta para `/sitemap.xml`.
- Correção do markup do bloco do YouTube.
- Testes de preflight, smoke, rotas HTTP, formulário/lead e renderização headless realizados na validação.

## Funcionalidades preservadas
Catálogo, páginas de vestidos, galeria com filtros, lightbox, vídeos, YouTube, FAQ, agendamento, WhatsApp, painel administrativo, autenticação, CRM de leads, API, SEO, robots.txt e sitemap.xml.
